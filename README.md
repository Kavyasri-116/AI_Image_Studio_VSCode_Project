# AI Image Studio

A polished beginner-friendly AI Image Generator web project built for VS Code.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- AI-style image generation interface
- Prompt input
- Multiple visual styles
- Aspect ratio selection
- Generated image preview
- Download generated SVG image
- Responsive design

## Important
This version is a **browser-only demo**. It generates a stylized SVG based on the user's prompt; it does not call a real generative AI model.

To connect a real AI image-generation service later, the `createSvg()` function in `script.js` can be replaced with a secure backend/API integration.

## How to Run in VS Code
1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Use Live Server, or open the HTML file directly in a browser.
4. Enter a prompt.
5. Select a style.
6. Click **Generate Image**.
